# Feji Studios

A responsive studio website for Orka and Styrka, built with React, Vinext, and the Sites starter.

## Development

`npm install` then `npm run dev`. `npm run build` produces the Cloudflare-compatible deployment. `npx tsc --noEmit` checks types; `npx oxlint app` checks authored application code. The starter's unused component catalog has existing lint findings under the full `npm run lint` command.

## Content

- Home and product story: `app/page.tsx`
- Colors, responsive styling, and motion fallbacks: `app/globals.css`
- Scroll behavior: `app/motion.tsx`
- Legal content: `app/legal-content.ts`
- Outstanding release details: `CONTENT_REVIEW.md`

The supplied imagery is optimized to WebP without changing its composition or colors. Original files remain in their supplied locations. The project adds no analytics, forms, or tracking scripts. Hosting request handling is independent of app privacy disclosures.

Routes: `/`, `/orka`, `/styrka`, `/orka/privacy`, `/orka/terms`, `/styrka/privacy`, `/styrka/terms`. Legacy `/privacy` and `/terms` redirect permanently to Styrka's pages.

## Open in Visual Studio Code

The complete editable project is in this folder, not just the compiled website.

1. In VS Code, choose **File → Open Workspace from File…** and select `Feji-Studios.code-workspace` in the parent `Website` folder. Alternatively, choose **File → Open Folder…** and select this `feji-studios` folder.
2. Choose **Terminal → New Terminal**. It should open in `feji-studios`.
3. Run `npm run dev`. Dependencies are already installed on this computer. For a fresh checkout, run `npm install` first.
4. Open the Local URL printed in the terminal. Port 3000 is preferred; if busy, the server picks another port.
5. Edit `app/page.tsx` for the homepage and `app/globals.css` for styling. Saving updates the preview.

There is no import step and no need to recreate the project. `dist` is generated by `npm run build`; edit the source files in `app`, not `dist`.

## SEO and navigation verification

Navigation uses native anchors deliberately: the installed Vinext Link component threw `TypeError: e is not a function` on the live site and prevented in-page and internal navigation. Keep ordinary links as anchors unless the framework integration is separately verified in a production build. This also avoids link-prefetch JavaScript and supports navigation without JavaScript.

After building, run `npm run start -- --port 3011`, then `node scripts/check-seo.mjs http://localhost:3011`. The smoke check covers metadata, canonicals, headings, JSON-LD, anchors, 404s, legacy redirects, the sitemap, robots.txt and the existing social image.

The domain middleware redirects only `www.feji.fi` to HTTPS `feji.fi`, preserving paths and queries. To test locally, start a separate preview with `npm run start -- --port 3012 --local-upstream www.feji.fi`; request `/orka/privacy?ref=test` and expect a 308 to `https://feji.fi/orka/privacy?ref=test`.

After deployment, submit `https://feji.fi/sitemap.xml` in Google Search Console and inspect the homepage plus both app pages. Search indexing and rankings are not guaranteed. App structured data describes confirmed features; no prices, ratings or reviews are fabricated, so software-app rich-result eligibility is not claimed. Existing social artwork is preserved.
